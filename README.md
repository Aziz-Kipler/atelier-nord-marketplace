# Atelier Nord — Curated Fashion & Footwear Marketplace

> **Селективный маркетплейс премиальной одежды, обуви, головных уборов и аксессуаров в стиле Ozon / Lamoda Premium.**

Разработано для профиля: **[Aziz-Kipler](https://github.com/Aziz-Kipler)**

---

## 🌟 Ключевые возможности платформы

### 1. Ролевой доступ (RBAC: Покупатель и Администратор)
- **Покупатель (Customer):**
  - Главная страница с коллекциями и промо-баннерами
  - Каталог с фильтрами по категориям (*Одежда, Обувь, Головные уборы, Аксессуары*), брендам, ценам и наличию
  - Полноценная страница товара (PDP) с выбором размеров, цветов и отзывов
  - Корзина с промокодом `NORD15` (-15%), расчетом доставки и выбором способа оплаты
  - Избранное (Wishlist)
  - Личный кабинет с трекингом посылок и историей заказов
  - **Публикация своих товаров**: любой клиент может нажать **«+ Продать товар»** и выставить вещь на продажу с несколькими фотографиями!
- **Администратор (Admin):**
  - Аналитическая панель (выручка, средний чек, количество заказов, доли категорий)
  - Управление каталогом (добавление, редактирование, удаление товаров, остатки на складе)
  - Управление клиентской базой (VIP-статусы, блокировка/разблокировка)
  - Управление заказами (смена статусов: *«В обработке»*, *«В пути»*, *«Доставлен»*, *«Отменен»*) и модерация отзывов

### 2. Мульти-загрузка фотографий товара
- Возможность прикрепить несколько ракурсов (вид спереди, сзади, на модели, фактура ткани)
- Интерактивная галерея со счетчиком фото (`1/3`, `2/3`) на карточке и странице товара

### 3. Современный UI & UX в стиле ведущих маркетплейсов
- Крупные четкие цены без слипания цифр
- Бейджи реальных скидок (`-16%`) и звезды рейтинга
- Мультиязычность (**RU / EN**) в один клик
- Поддержка **тёмной и светлой темы** с сохранением в `localStorage`
- Полная адаптивность под смартфоны и планшеты

## 🛠 Технологический стек

- **Frontend:** React 19, TypeScript, Vite
- **Стилизация:** Tailwind CSS
- **Иконки:** Lucide React
- **Анимации & Конфетти:** Canvas Confetti, CSS Transitions
- **Хранение данных:** State Management + LocalStorage persistence

## 🚀 Быстрый запуск проекта

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Aziz-Kipler/atelier-nord-marketplace.git
   cd atelier-nord-marketplace
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте приложение в браузере:
   ```
   http://localhost:3000
   ```
